# Mod-Name
Tome Fusion (Slug: tome-fusion)

# Kurzbeschreibung (max. ~80 Zeichen)
Addiere Buch-Level im Amboss - mit einer festen Obergrenze pro Verzauberung.

# Modrinth-Seitentext
## Tome Fusion

Im Vanilla-Amboss ergeben zwei Schaerfe-II-Buecher nur Schaerfe III. **Mit Tome Fusion werden die Level einfach addiert.**

### Beispiele
- Schaerfe II + Schaerfe II = **Schaerfe IV**
- Schaerfe V + Schaerfe III = **Schaerfe VIII**
- Schaerfe VIII + Schaerfe V = Schaerfe XIII -> begrenzt auf **Schaerfe X**

### Obergrenze
Das Ergebnis ist nie hoeher als das **Doppelte des Vanilla-Maximums** der Verzauberung
(Schaerfe 5 -> max. 10, Federfall 4 -> max. 8).

### Details
- Gilt fuer verzauberte Buecher im Amboss (Buch + Buch)
- Verschiedene Verzauberungen auf beiden Buechern werden uebernommen
- Fuer den Singleplayer gedacht
- Benoetigt Fabric API
